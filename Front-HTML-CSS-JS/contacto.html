Flujo de Atención de Solicitudes y Tickets

Ciclo de vida ordenado para la gestión de incidentes y novedades de carnetización:

  1. Radicación del Requerimiento

    El titular envía el formulario con sus datos institucionales y detalle del caso.

  2. Asignación y Verificación Técnica

    El analista de soporte comprueba la identidad del usuario en la base de datos de credenciales.

  3. Ejecución de la Acción Correctiva

    Se emite el nuevo carnet digital, se actualiza la vigencia o se inhabilita el código QR previo.

  4. Notificación y Cierre del Caso

    El usuario recibe confirmación por correo y su nuevo carnet queda operativo al instante.
