Instrucciones para la Expedición y Uso del Carnet

Guía técnica para el personal de recursos humanos y administradores del sistema:

  1. Diligenciar los Campos del Titular

    Escribe el nombre completo, rol oficial y número de cédula o tarjeta de identidad.

  2. Verificar la Previsualización Dinámica

    Observa cómo la credencial refleja cada tecla presionada sin necesidad de recargar la página.

  3. Seleccionar Estado de Vigencia

    Asigna 'ACTIVO' para acceso libre, 'EN REVISIÓN' para permisos provisionales o 'VENCIDO'.

  4. Guardar y Comprobar con el Escáner QR

    Presiona el botón de guardar y utiliza el validador QR para corroborar que el código es reconocido.
